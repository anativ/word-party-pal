# Lingua Party

Le'ts build an app to learn English
we will upload a list of words in English and Hebrew
The game will show a word in Hebrew and a textbox to write the English word.
after writing the English word it will reveal the word and give a score with (party theme) on success if not will show fail and show the answer.
it should also track the success rate of each word in the DB
It should be mobile frendaly as it will be mostly use from mobile
