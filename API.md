# Words API

A secured REST API for adding, updating, and deleting **words** and **verbs** programmatically — same power as the Admin panel, usable from scripts.

## Endpoint

```
POST https://woorksdbyerlkgtyvlrw.supabase.co/functions/v1/words-api
```

## Authentication

Every request must include your secret key in the `x-api-key` header:

```
x-api-key: <YOUR_WORDS_ADMIN_API_KEY>
```

The key was chosen when the API was set up and stored encrypted in the backend. If you ever lose it, a new one can be saved from the project's secrets settings.

Requests without the key — or with a wrong key — are rejected with `401 Unauthorized`.

## Request format

Send a JSON body with three fields:

| Field    | Values                                        | Description                                  |
|----------|-----------------------------------------------|----------------------------------------------|
| `table`  | `"words"` or `"verbs"`                        | Which list to modify                         |
| `action` | `"insert"`, `"update"`, `"upsert"`, `"delete"` | What to do                                   |
| `items`  | array of objects (max 1000)                    | The data (see shapes below)                  |

**Word shape** (`table: "words"`):

```json
{ "english": "house", "hebrew": "בית" }
```

**Verb shape** (`table: "verbs"`):

```json
{ "hebrew": "ללכת", "past": "went", "present": "go" }
```

### Actions

- **insert** — adds new items (no `id` needed).
- **update** — every item **must** include its `id` (a UUID).
- **upsert** — items **with** an `id` are updated; items **without** an `id` are inserted. Best for bulk sync.
- **delete** — every item only needs its `id`.

## Examples

### Add words

```bash
curl -X POST 'https://woorksdbyerlkgtyvlrw.supabase.co/functions/v1/words-api' \
  -H 'Content-Type: application/json' \
  -H 'x-api-key: YOUR_KEY' \
  -d '{
    "table": "words",
    "action": "insert",
    "items": [
      { "english": "house", "hebrew": "בית" },
      { "english": "dog",   "hebrew": "כלב" }
    ]
  }'
```

### Bulk upload / sync verbs (upsert)

```bash
curl -X POST 'https://woorksdbyerlkgtyvlrw.supabase.co/functions/v1/words-api' \
  -H 'Content-Type: application/json' \
  -H 'x-api-key: YOUR_KEY' \
  -d '{
    "table": "verbs",
    "action": "upsert",
    "items": [
      { "hebrew": "ללכת", "past": "went", "present": "go" },
      { "id": "existing-verb-uuid", "hebrew": "לאכול", "past": "ate", "present": "eat" }
    ]
  }'
```

### Update a word

```bash
curl -X POST '.../words-api' \
  -H 'Content-Type: application/json' \
  -H 'x-api-key: YOUR_KEY' \
  -d '{
    "table": "words",
    "action": "update",
    "items": [ { "id": "word-uuid", "english": "home", "hebrew": "בית" } ]
  }'
```

### Delete a word

```bash
curl -X POST '.../words-api' \
  -H 'Content-Type: application/json' \
  -H 'x-api-key: YOUR_KEY' \
  -d '{
    "table": "words",
    "action": "delete",
    "items": [ { "id": "word-uuid" } ]
  }'
```

## Responses

Success:

```json
{ "table": "words", "action": "insert", "inserted": 2, "updated": 0 }
```

With invalid items (valid ones still processed):

```json
{
  "table": "words",
  "action": "insert",
  "inserted": 1,
  "updated": 0,
  "invalidItems": [{ "index": 1, "errors": { "...": "field errors" } }]
}
```

Errors: `401` wrong/missing key · `400` bad JSON or missing `id` on update · `405` not POST · `500` server issue.

## Notes

- Finding an existing item's `id`: currently use the Admin panel or ask for a lookup action — IDs are UUIDs generated by the database.
- Deleting a word does **not** automatically delete players' stats for it in all cases (database rules handle cleanup for linked stats).
